# Title materials

- `title-metal.jpg`: resized 512px diffuse map from [Metal Plate](https://polyhaven.com/a/metal_plate) by Rob Tuytel, Poly Haven. [CC0](https://polyhaven.com/license). Download: https://dl.polyhaven.org/file/ph-assets/Textures/jpg/1k/metal_plate/metal_plate_diff_1k.jpg
- Titanium and copper layer this industrial texture with colored highlights.
- Carbon weave, opal, mercury, sapphire, plasma, and obsidian are original CSS procedural materials. Ice and lava reuse the existing local images.
