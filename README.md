# vicorico.fun

Static personal website for `vicorico.fun`.

## Files

- `index.html` - commercial homepage: positioning, selected work, services, and email contact.
- `home.css` / `home.js` - responsive homepage styling, contact analytics, and email copying.
- `lab.html` - extended project collection and career archive.
- `game.html` - playable Game CV page.
- `styles.css` - shared screen and print styling.
- `site.js` - lightweight GitHub API integration for public repos and stars.
- `assets/vicorico-mark.svg` - local brand mark and favicon.
- `vercel.json` - Vercel static hosting settings.

## Edit

Contact links use the email from the existing CV. Featured projects are described as independent builds; the homepage does not claim unverified client outcomes.

Plausible events: `Contact Click` (kind: product, automation, partnership, general, email, copy-email, or x) and `Project Click` (kind: project name). Configure corresponding custom-event goals in Plausible to report them. Contact clicks indicate intent, not a submitted inquiry or booked call. No inquiry text or email content is sent as event properties.

To strengthen the proof later, add permission-cleared collaborator quotes, actual product screenshots, and attributable outcomes with dates and sources. Add a booking link when a real scheduling URL is available.

Open `index.html` directly in a browser to preview the site.
